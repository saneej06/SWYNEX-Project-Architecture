Hello everyone! I am happy to share my SWYNEX Internship Task 01: Project Architecture.

My project is PricePulse, a local grocery price comparison system for Sri Lanka.

The problem is that grocery prices differ between shops, and customers may spend time checking them.

I designed a React frontend, an Express.js REST API, and a PostgreSQL database.

The main features are product search, district-wise shop price comparison, user price submissions, and admin approval.

I have prepared an architecture document, database ER diagram, REST API routes, and a starter project repository.

This is an academic prototype with fictional demo prices, not a live price service.

Thank you to SWYNEX Technologies for this learning opportunity.
